   при `PYQUIZ_SANDBOX=auto` сервер сам выберет namespaces, если WSL есть.

## Команды

```
python server.py --local             # только этот компьютер
python server.py --local --dev       # панель разработчика, F2
python server.py --no-code           # без выполнения кода учеников

python run_all_checks.py             # всё, включая node
python run_all_checks.py --quick     # без node
python run_all_checks.py --only verify_server check
python verify_dungeon.py             # подземелье; при сбое код 1
node play_dungeon.js --games=20      # бот проходит подземелье

python launch_game.py                # классная версия + браузер
python launch_standalone.py          # standalone + полноэкранный браузер
python tools/build_web.py            # собрать standalone/build/
python tools/fetch_pyodide.py        # локальный Pyodide (офлайн)
python tools/package_web.py          # dist/pydungeon-standalone-<версия>.zip
```

`?debug=1` открывает `window.__pyquiz`, `__setFloor`, `__validateFloor`,
`__buildFloor` — только при запуске с `--dev`.

## Что сделано в 1.6.0

- **Стартовое меню игры.** Полноэкранный экран до деревни: вход или
  регистрация, «Продолжить поход» с этажом и золотом, «Играть», «Как играть»,
  переход в панель учителя и на главную. В веб-сборке вместо PIN — локальное
  имя. Кнопка «Меню» в шапке открывает тот же экран во время игры.
- **Настройки.** Звук и громкость (синтезированные эффекты без файлов),
  полный экран, «меньше анимации», сброс подсказок. Хранятся в
  `pyquiz_settings_v1` и переживают перезагрузку.
- **Звук.** Верный и неверный ответ, победа и поражение; аудиоконтекст
  создаётся по первому действию игрока.
- **Под меню игра не идёт.** Клавиши, E и пропуск хода не срабатывают, пока
  открыт стартовый экран; подсказка управления веб-сборки под меню скрыта.
- **Исправлен вход и регистрация.** `applyServerProfile` объявляла
  `const merged` и переприсваивала её ниже: после создания сессии вход падал
  с «Сервер недоступен». Теперь профиль применяется, страница перезагружается.
- Проверки: `verify_web` — 14/14 в Edge, `verify_server` — 85/85,
  `verify_dungeon` — новая проверка серверной копии профиля.

## Что сделано в 1.5.0

- **Калибровка перед первым спуском.** Шесть вопросов из общего банка, по два
  уровня 1–3. Уровень 1–3 хранится в `profile.knowledge`, синхронизируется с
  сервером, переезжает между компьютерами; у стража можно пройти заново или
  пропустить (тогда базовый уровень).
- **Выдача с поправкой.** `floorLevels()` сдвигает вопросы и задания на
  ступень вниз/вверх (`knowledgeOffset`), не трогая силу монстров.
- **Учительская таблица.** `/results`: новая колонка «Старт», прежняя
  «Уровень» переименована в «Итог». `knowledgeLevel` проходит через
  `/api/submit` и `clean_result`.
- **Сервер.** `clean_profile` принимает `knowledge` по белому списку:
  уровень 0–3, 6 ответов, 12 баллов; старые профили получают 0.
- Проверки: 85 в `verify_server`, 966+ в `verify_dungeon`; полный прогон 7/7.
