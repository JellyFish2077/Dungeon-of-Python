# Деревня: как править вручную

Деревня задана текстом и данными, отдельного редактора карты нет.
Правки делаются в `static/village-content.js`, затем сборка и проверки.

## 1. Где что лежит

| Файл | Что там |
|---|---|
| `static/village-content.js` | карта `VILLAGE_MAP`, дома, жители, таблички, интерьеры |
| `static/game.js` | отрисовка, двери, подписи, состояние «построено» |
| `tools/checks.js` | проверки деревни, домов и интерьеров |
| `docs/VILLAGE_MAP_PLAN.md` | текущая карта и координаты |
| `standalone/build` | собранная игра; сюда смотрит сервер |

## 2. Карта

`VILLAGE_MAP` — массив строк 30×18. Все строки обязаны быть одной длины.

| Символ | Что это | Проходимость |
|---|---|---|
| `#` | стена дома | нет |
| `D` | открытая дверь | через дверь входишь |
| `d` | запертая дверь | нет, пока не построено |
| `p` | дорожка | да |
| `.` | трава | да |
| `T` | дерево | нет |
| `F` | забор | нет |
| `W` | колодец | нет |
| `C` | костёр | да |
| `S` | табличка | да |
| `o` | бочка | нет |
| `l` | поленница | нет |
| `t` | стол | нет |
| `c` | стул | нет |
| `r` | ящик | нет |
| `a` | наковальня | нет |
| `V` | спуск в подземелье | нет |

Пример: поставить бочку в траву на `x=12, y=4` — заменить `.` на `o` в строке `y=4`.
Не ставь `T`, `F`, `o`, `l` и мебель на `p`, на дверь или на клетку перед дверью:
проверка достижимости это поймает.

## 3. Дома

Открытые дома — `VILLAGE_HOUSES`, недостроенные — `VILLAGE_SEALED`.

```js
elder: {
  name: "Дом старосты", roof: "blue",
  box: { x0: 3, y0: 2, x1: 7, y1: 5 },
  door: { x: 5, y: 5 }, exit: { x: 4, y: 6 }
}
```

- `box` обязан совпадать со стенами `#` в карте.
- `door` — клетка `D` или `d` внутри `box`.
- Дверь должна быть **на нижней стене**: `door.y === box.y1`. Тогда фасад
  снизу, а крыша сверху. Это проверяет тест «у всех домов фасад снизу».
- `exit` — клетка появления внутри комнаты. У всех комнат это `4,6`;
  если меняешь дверь `X` в интерьере, поменяй и `exit`.
- `roof`: `red`, `blue`, `green` или `brown`.
- У `VILLAGE_SEALED` есть `locked: true`; из этого флага рисуются леса,
  а после постройки — припасы у фасада.

Если двигаешь дом:
1. Перенеси блок `#` и дверь в `VILLAGE_MAP`.
2. Поменяй `box` и `door` в `VILLAGE_HOUSES`/`VILLAGE_SEALED`.
3. Убедись, что клетка под дверью (`door.y + 1`) — пол, а не стена и не декор.
4. Прогони проверки.

## 4. Жители

`VILLAGE_NPCS`:

```js
{ key: "banker", name: "Казначей", place: "bank", at: { x: 4, y: 2 } }
```

- `place: "village"` — житель на улице.
- `place: "bank"` — житель внутри банка; ключ должен совпадать с `HOUSE_MAPS.bank`.
- В интерьере маркер `1` обязан стоять в той же клетке, что и `at`.
- Перед жителем должна быть свободная клетка: игрок подходит и нажимает `E`.

## 5. Таблички

`VILLAGE_SIGNS`:

```js
{ x: 23, y: 6, title: "Указатель", subtitle: "Деревня", text: "..." }
```

- На карте в этой клетке должен стоять `S`.
- Если `S` есть, а записи в `VILLAGE_SIGNS` нет, загрузка упадёт с понятной ошибкой.
- У табличек строек есть `building`, `builtTitle`, `builtSubtitle`, `builtText`.
  После постройки текст меняется на «Открыто».

## 6. Интерьеры

`HOUSE_MAPS` — комнаты 9×7:

```js
bank: [
  "#########",
  "#siiii#r#",
  "#tci1i#r#",
  "#inninni#",
  "#iiiiiii#",
  "#riiiiic#",
  "####X####"
]
```

- `#` — стена, `i` — пол, `X` — выход, `1` — житель.
- Мебель: `s` полка, `r` ящик, `n` прилавок, `t` стол, `c` стул,
  `b` кровать, `a` наковальня, `f` очаг, `w` верстак, `k` котёл.
- Выход `X` стоит внизу по центру (`4,6`).
- От двери до жителя и до каждой проходимой клетки должен быть путь.
- Дверь, житель и мебель не должны запирать друг друга.

## 7. Декор

- Деревья, заборы, бочки и поленницы — непроходимые. Не ставь их на
  дорожки, перед дверями и на путь к жителю.
- Стол, стул, ящик и наковальня кладутся на чистый грунт: у этих тайлов
  нет травы под ними.
- Леса у строек и припасы после постройки не задаются в карте — они
  появляются из `villageMaterials` по флагу `locked`/`built`.

## 8. Сборка и проверка

```powershell
python tools/build_web.py
python run_all_checks.py --quick
python run_all_checks.py
```

- Сервер отдаёт `standalone/build`, а не `static`. После правок обязательно
  пересобери и перезагрузи страницу.
- Игра: `http://localhost:8080/game.html`.
- Кампания v2: `http://localhost:8080/game.html?campaign=v2`.
- `--quick` — контент и подземелье; полный прогон добавляет веб-сборку.

## 9. Частые ошибки

| Ошибка | Причина |
|---|---|
| `деревня: строка N длиной ...` | в строке карты не 30 символов |
| `дом «...» ждёт стену в X,Y` | `box` не совпадает с `#` в карте |
| `дверь дома «...» не на краю` | дверь не на `y0/y1` |
| тест «фасад снизу» падает | дверь на верхней стене |
| `у таблички ... нет текста` | `S` без записи в `VILLAGE_SIGNS` |
| дверь недостижима | перед дверью стена, декор или нет дорожки |
| житель отрезан | мебель перекрыла путь в комнате |

## 10. Сохранения и кампания

- Карта деревни не хранится в профиле: правки не ломают золото,
  материалы и уровни построек.
- Если сохранённая позиция героя в деревне стала стеной, игра
  поставит его на точку появления.
- Радиальные острова и дань дракону работают только в кампании v2;
  `CAMPAIGN_V2` по умолчанию выключен, смотри `?campaign=v2`.

## 11. Визуальный редактор

Для правки карты мышью есть отдельное приложение
`tools/village-editor`:

```powershell
npm install
npm run dev
```

Открой `http://localhost:5174/`. Редактор читает текущий
`static/village-content.js`, позволяет красить тайлы, двигать рамки
домов и двери, править таблички и экспортировать готовые блоки.
Подробности — в `tools/village-editor/README.md`.
