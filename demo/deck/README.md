# Демо-колода PyDungeon

Три слайда об игре в визуальном языке `DESIGN.md` (полевой журнал: бумага,
ржавчина, Literata + IBM Plex Mono), собранные двумя способами.

| Файл | Что это |
|---|---|
| `pydungeon-deck.pptx` | нативная колода 16:9, редактируется в PowerPoint |
| `pydungeon-deck.html` | самодостаточная HTML-колода: шрифты и снимок вшиты base64 |
| `render/slide-1..3.png` | рендер PPTX (LibreOffice → PDF → PNG) |
| `render/html-1..3.png` | скриншоты HTML-слайдов (Edge / Playwright) |
| `render/compare.png` | контактный лист: PPTX сверху, HTML снизу |
| `render/notes-panel.png` | панель заметок в HTML (клавиша `N`) |
| `render/*.pdf` | PDF из обоих вариантов |
| `notes.py` | заметки докладчика: один источник для PPTX и HTML |

## Сборка

```bash
python demo/deck/build_deck.py      # .pptx + кроп снимка боя
python demo/deck/build_html.py      # .html
python demo/deck/make_compare.py    # compare.png (нужны готовые рендеры)
```

Рендер PPTX:

```powershell
powershell -File demo/deck/render.ps1
```

HTML: открыть `pydungeon-deck.html` в браузере. Управление — стрелки, пробел,
`Home`/`End`, `N` — заметки, `P` — печать (по одному слайду на страницу).
Служебный режим `?render=1&slide=2` показывает один слайд без масштабирования —
из него снимаются скриншоты.

## Заметки докладчика

`notes.py` — единственный источник, из него заметки попадают и в `.pptx`
(заметки слайда: «Вид → Заметки», в показе — режим докладчика), и в HTML
(панель справа, клавиша `N`).

Тайминг: ~35 / 70 / 45 секунд, всего около двух с половиной минут. В заметках
есть вопрос залу на первом слайде, разбор реального вопроса с экрана на втором
и блок «если спросят» на третьем.

Одно место оставлено под тебя: `[вставь свою цифру — одна фраза, без
подробностей]` в заметках третьего слайда. Всё остальное — проверяемые факты
из `README.md`; придуманных историй там нет, поэтому если нужна личная
подводка — добавь её сам, а не подгоняй заметки под неё.

## Что важно знать

- **Шрифты.** Literata и IBM Plex Mono лежат в `static/landing/fonts/` (OFL).
  Для рендера PPTX они установлены в профиль пользователя
  (`%LOCALAPPDATA%\Microsoft\Windows\Fonts`). HTML их вшивает, установка не нужна.
- **Кроп снимка.** Бой вырезается из `dist/journal-preview/top.png`,
  координаты — в `crop_battle()`. При пересборке лендинга кроп надо проверить.
- **Чего нет в PPTX.** Переходов, анимаций и SmartArt: `python-pptx` их не умеет.
  Для живой колоды это не нужно, для доклада с анимациями — нужен COM-путь.
- **Совпадение вариантов.** Сетка одна (1280×720, поля 86 px), но переносы строк
  в HTML и PowerPoint считаются по-разному: текст может лечь на строку иначе.
