# Макеты инвентаря

Три раскладки одного и того же окна в «тихом» языке: без золотых рамок,
с тонкими линиями, Handjet в заголовке и настоящими иконками предметов.
Макет собран на реальных данных из `items.js` и `sprites.js`, фон — тайлы
подземелья из `terrain.js`.

## Как открыть

Из корня репозитория:

```powershell
python -m http.server 8770
```

Затем:

```text
http://127.0.0.1:8770/static/ui-mockup/inventory.html
```

Чистый кадр без панели управления: `?clean=1`.

## Варианты

1. **Створка** — правая колонка на всю высоту, HUD на время открытия
   скрывается. Карта остаётся видна слева, ничего не перекрывается.
   Хорошо ложится на текущую игру: инвентарь открывается как отдельная
   поверхность, а не как карточка по центру.
2. **Лист** — плоская панель по центру 780×560: слева кошелёк, статы и
   снаряжение, справа сумка со фильтрами и списком. Шапка и футер
   закреплены, скроллится только список.
3. **Сетка** — панель 840×580: снаряжение строкой сверху, сумка сеткой
   ячеек, справа карточка выбранного предмета с действиями. Самый
   «игровой» вариант, хорошо работает с иконками.

## Что проверяет макет

- HUD скрывается при открытом инвентаре — на 1280 он больше не обрезается
  панелью.
- Заголовок и футер не уезжают: скроллится только содержимое.
- Фильтры «Всё / Снаряжение / Зелья» считают предметы и дают пустые
  состояния.
- Полная сумка (17 предметов) и короткая (6) — видно поведение скролла.
- Иконки, редкость и эффекты берутся из настоящих данных игры.

## Управление

- `1` `2` `3` — вариант.
- `I` или `Esc` — открыть/закрыть инвентарь.
- `V` — полная/короткая сумка.
- `F` — следующий фильтр.
- `H` — скрыть панель управления.

## Что решаем

- Створка справа или центрированная панель.
- Показывать ли список строками (имя + эффект) или сеткой иконок.
- Нужна ли карточка выбранного предмета с действиями.
