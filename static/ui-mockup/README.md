# Макеты игрового интерфейса

Визуальный прототип, не production-код. Показывает, как может выглядеть
экран подземелья и бой, если привести их к «тихому» языку нового главного
меню: без золотых карточек, с пиксельным Handjet в заголовках и тонкими
линиями вместо рамок.

Макет использует настоящие `terrain.js`, `sprites.js`, шрифты и тайлы из
`static/`. В публичную сборку `standalone/build` он не копируется.

## Как открыть

Из корня репозитория:

```powershell
python -m http.server 8770
```

Затем открыть:

```text
http://127.0.0.1:8770/static/ui-mockup/index.html
```

Для чистого кадра без панели управления добавь `?clean=1`.

## Варианты

1. **Тихий** — интерфейс живёт прямо на карте: у HUD и мини-карты нет
   подложек, только тонкие линии и тени текста. Бой — нижняя панель без
   рамки, варианты ответа — строки-кнопки.
2. **Гримуар** — тёмные панели с тонкой золотой рамкой. Ближе к текущей
   игре: панель героя, мини-карта и бой читаются как отдельные предметы,
   но без толстых рамок и угловых засечек.
3. **Консоль** — моноширинный терминал: `[Этаж]`, `MAP.SYS`, `[A] 1`,
   `> Атака`. Никаких скруглений и декора, только стальная линия.

## Что показано

- **Карта**: верхнее меню, панель героя (уровень, HP, XP, золото, глава),
  мини-карта с зумом, подсказка управления, пропуск хода.
- **Бой**: заголовок сцены, портреты и HP бойцов, панель с вопросом,
  кодом, четырьмя вариантами ответа и действиями.

Мини-карта и фон рисуются из одной и той же карты комнат, поэтому экран и
миникарта не расходятся.

## Управление

- `1` `2` `3` — сменить вариант.
- `V` — карта / бой.
- `H` — скрыть панель управления и подсказку клавиш.
- Клик по варианту ответа — подсветить его.

## Что решаем

- Нужны ли HUD и миникарта совсем без подложек (вариант 1) или оставить
  лёгкие панели (вариант 2).
- Остаётся ли золото акцентом или интерфейс уходит в сталь/стекло.
- Насколько «терминальным» может быть бой без потери читаемости.

## Следующий шаг

После выбора варианта переносим по частям:

1. Палитра и типографика — в `game.css` (переменные HUD и нижней панели).
2. Панель героя и мини-карта — разметка в `game.html`, стили в `game.css`.
3. Бой — `renderBattle()` и классы `.battle-panel`, `.battle-ask`,
   `.answer`; логика ответов не меняется.
4. Проверки — `verify_web.py` (размеры, шрифты, отсутствие рамок) и
   скриншот для Itch.
