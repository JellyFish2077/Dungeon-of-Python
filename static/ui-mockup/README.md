# Макеты игрового интерфейса

Визуальный прототип, не production-код. Показывает, как может выглядеть
экран подземелья и бой, если привести их к «тихому» языку нового главного
меню: без золотых карточек, с пиксельным Handjet в заголовках и тонкими
линиями вместо рамок.

**Выбран вариант 1 «Тихий»** и перенесён в игру: HUD и мини-карта живут
прямо на карте без подложек, бой — плоская нижняя панель, ответы — тонкие
строки. Рабочая версия — `static/game.css`; этот макет остаётся
справочником для будущих правок.

Макет использует настоящие `terrain.js`, `sprites.js`, шрифты и тайлы из
`static/`. В публичную сборку `standalone/build` он не копируется.

## Как открыть

Из корня репозитория:

```powershell
python -m http.server 8770
```

Затем открыть:

```text
http://127.0.0.1:8770/static/ui-mockup/index.html
```

Для чистого кадра без панели управления добавь `?clean=1`.

## Варианты

1. **Тихий** — интерфейс живёт прямо на карте: у HUD и мини-карты нет
   подложек, только тонкие линии и тени текста. Бой — нижняя панель без
   рамки, варианты ответа — строки-кнопки.
2. **Гримуар** — тёмные панели с тонкой золотой рамкой. Ближе к текущей
   игре: панель героя, мини-карта и бой читаются как отдельные предметы,
   но без толстых рамок и угловых засечек.
3. **Консоль** — моноширинный терминал: `[Этаж]`, `MAP.SYS`, `[A] 1`,
   `> Атака`. Никаких скруглений и декора, только стальная линия.

## Что показано

- **Карта**: верхнее меню, панель героя (уровень, HP, XP, золото, глава),
  мини-карта с зумом, подсказка управления, пропуск хода.
- **Бой**: заголовок сцены, портреты и HP бойцов, панель с вопросом,
  кодом, четырьмя вариантами ответа и действиями.

Мини-карта и фон рисуются из одной и той же карты комнат, поэтому экран и
миникарта не расходятся.

## Управление

- `1` `2` `3` — сменить вариант.
- `V` — карта / бой.
- `H` — скрыть панель управления и подсказку клавиш.
- Клик по варианту ответа — подсветить его.

## Инвентарь

Отдельная страница с тремя раскладками: `inventory.html` (см.
`inventory-README.md`). Верхнее меню, HUD и фон там те же.


## Что решено

- Выбран вариант 1 «Тихий»: HUD, мини-карта и подсказки без подложек.
- Золото осталось только акцентом (монета, глава), интерфейс — сталь и
  холодный синий.
- Бой — нижняя панель с одной линией сверху; действия — текстовые
  кнопки, ответы — тонкие строки.
- У героя, жителей, монстров и предметов на карте убраны цветные
  ореолы: осталась только мягкая тень под спрайтом.
- Подсказки при наведении убраны: интерфейс не показывает всплывающих
  карточек и нативных `title`.

## Где это в игре

- `static/game.css` — блоки «ТИХИЙ ИНТЕРФЕЙС» и «БЕЗ СВЕЧЕНИЯ» в конце
  файла: токены, верхнее меню, HUD, мини-карта, бой, панели, журнал,
  лавка, кузница, диалоги и карта.
- `static/saves.css` — окно сохранений в той же палитре.
- `static/game.js` — цвет рамки обзора на мини-карте.
- `tools/checks.js` — проверки токенов, HUD без подложки, рамки
  мини-карты, плоской панели боя и строк ответов.
- `verify_web.py` — проверка, что у полотна мини-карты есть своя рамка.

## Что осталось

- Макеты вариантов 2 «Гримуар» и 3 «Консоль» не переносятся: они
  остаются альтернативами на случай смены направления.
- Мобильная раскладка по-прежнему заморожена: игра рассчитана на ПК.
