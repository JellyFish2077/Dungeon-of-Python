# Phaser 3 prototype

Небольшой прототип на Phaser 3 для сравнения с текущим DOM/CSS-движком.
В игру не входит и ничего в ней не меняет.

## Запуск

```powershell
npm install
npm run dev:phaser
```

Открой `http://localhost:5175/`.

Сборка:

```powershell
npm run build:phaser
```

Результат — `dist/phaser-prototype`.

## Что показывает

- настоящую карту деревни 30×18 из `static/village-content.js`;
- тайлы, крыши, фасады, двери, деревья, заборы и декор из `static/terrain.js`;
- героя и двух уличных жителей из `static/sprites.js`;
- ходьбу WASD/стрелками с коллизиями;
- камеру с follow и зумом колесом;
- подсказку «E — …» и DOM-окно диалога поверх canvas;
- счётчик FPS.

## Что это значит

Прототип специально маленький: он проверяет, как в Phaser выглядят
существующие тайлы, камера, ввод и DOM-окна. Он **не** заменяет игру:
бои, инвентарь, сохранения, диалоги и вся логика остаются в текущем
движке.

Сборка Phaser весит около 1,4 МБ (≈370 КБ gzip) только за счёт самого
движка. Это главный аргумент против переезда без отдельного решения.
