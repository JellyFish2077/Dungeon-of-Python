# PyDungeon — стиль графики

Вертикальный срез: тёмное фэнтези, чистые 32×32, ограниченная палитра.
Источник истины — `.aseprite` в `tools/art/aseprite/`. PNG в
`tools/art/src_custom/` генерируются и вручную не правятся.

## Техническая рамка

| Параметр | Значение |
|---|---|
| Канвас | 32×32 px, RGBA |
| Прозрачность | фон полностью прозрачный, без «шахматки» и тени |
| Контур | 1 px, `#05070d`; у существ уже в исходнике |
| Свет | сверху-слева, тень снизу-справа |
| Масштаб в игре | клетка 32 px; существа занимают ~25×25 px |
| Якорь | низ по центру: ноги/основание на `y = 30`, центр `x = 16` |
| Палитра | `tools/art/palette.gpl`, 38 цветов |
| Фильтрация | `image-rendering: pixelated`; только целые масштабы |

Правила, которые проверяются глазами и сборкой:

- стены темнее пола: `build_art.py` приводит среднюю яркость стен к 0.18,
  пола — к 0.40; разница не меньше 0.1;
- у существ есть читаемый силуэт без внутренних деталей;
- на 25×25 px видно, кто это: форма важнее мелкой текстуры;
- золото (`9`, `A`, `B`) — только герой, магия и treasure;
- красный (`D`, `E`) — глаза врагов и опасность, не одежда героя;
- никакого сглаживания, градиентов и полупрозрачных пикселей;
- 8–12 цветов на спрайт, 1–2 акцентных цвета.

## Палитра

Полный список — в `tools/art/palette.gpl` (Aseprite: *Palette → Load Palette*).

| Роль | Коды | Зачем |
|---|---|---|
| Контур / тень | `O`, `0`, `1` | отделяет от любого пола |
| Синий героя | `2`, `3`, `4`, `5` | мантия, капюшон, сталь |
| Золото | `8`, `9`, `A`, `B` | пояс, пряжки, магия, сундук |
| Кость | `I`, `J`, `K` | скелет, череп |
| Зелень | `F`, `G`, `H` | слизь, гоблин, клевер |
| Болотно-оливковый | `X`, `Y`, `Z` | кожа гоблина |
| Багровый | `C`, `D`, `E` | глаза врагов, зелья |
| Фиолетовый | `L`, `M`, `N` | нетопырь |
| Коричневый | `P`, `Q`, `R`, `S` | дерево, кожа, рукояти |
| Камень | `T`, `U`, `V`, `t`, `u` | стены и пол |

## Язык форм

- **Герой** — компактный силуэт с капюшоном, посох выше головы, золотой
  пояс и застёжка. Лицо тёмное, видны только глаза: герой не должен
  сливаться со скелетом.
- **Слизь** — широкая капля с неровным низом, большой блик, красные глаза.
- **Крыса** — профиль вправо, длинный хвост, большое ухо, красный глаз.
- **Нетопырь** — широкие зубчатые крылья, маленькое тело, клыки.
- **Скелет** — большой череп, рёбра, тонкие конечности; глазницы — тёмные
  провалы с красной искрой.
- **Гоблин** — большие уши, широкое лицо, кожаная жилетка, кривой кинжал.
- **Предметы** — один крупный силуэт, один материал-акцент. Меч читается
  по диагонали, зелье — по круглой колбе, броня — по плечам и вырезу.
- **Тайлы** — стены: крупная кладка, 2 ряда по 16 px, швы не должны
  образовывать сетку при повторе 3×3. Пол: неровные камни, шов 1–2 px,
  никаких одинаковых квадратов.

## Aseprite

Файлы:

```
tools/art/aseprite/creatures.aseprite    player, slime, rat, bat, skeleton, goblin
tools/art/aseprite/creatures2.aseprite   spider, orc, troll, ghost, wolf, zombie, golem, demon, minotaur, vampire, lich, dragon, trader, priest, necromancer, shieldman
tools/art/aseprite/items.aseprite        short_sword, small_potion, … (6 предметов)
tools/art/aseprite/items2.aseprite       остальные 23 предмета
tools/art/aseprite/objects.aseprite      chest
tools/art/aseprite/objects2.aseprite     portal
tools/art/aseprite/objects3.aseprite     ore, rubble, lever, sign, loot bag
tools/art/aseprite/furniture.aseprite    table, chair, bed, shelf, crate, anvil, fireplace, workbench, cauldron, counter
tools/art/aseprite/terrain_01.aseprite   wall_0…wall_5, floor_0…floor_5 (пещеры)
tools/art/aseprite/terrain_02…10.aseprite  остальные 9 тем: по 6 стен и 6 полов
tools/art/aseprite/water.aseprite        base_0…base_3, wave_E/N/S/W_0…1
tools/art/aseprite/lava.aseprite         0…5
tools/art/aseprite/stairs.aseprite       down_0…1, up_0…1
tools/art/aseprite/traps.aseprite        spikes, pit, net, gas, blade, magical
tools/art/aseprite/doors.aseprite        0 — обычная, 1 — запертая
tools/art/aseprite/decor.aseprite        трава, мох, кости, кристаллы, обломки, колодец, колья, костёр
tools/art/aseprite/village.aseprite      стена, окно, 12 крыш, двор, NPC-база, дерево, земля
tools/art/aseprite/interior.aseprite     деревянные стены и дощатый пол домов
```

- Один кадр = один ассет. **Тег кадра = имя PNG** (`player`, `wall_0`).
- Все кадры лежат на слое `art`; фон не нужен.
- Палитра подключается из `tools/art/palette.gpl`.
- Для статичного среза один тег = один кадр. Если позже появятся
  анимации, тег может занимать несколько кадров, но экспорт нужно будет
  расширить: сейчас `export_aseprite.py` ожидает один PNG на тег.

Цикл правки:

```powershell
# 1. Открыть .aseprite, нарисовать, сохранить (Ctrl+S)
# 2. Экспорт PNG
python tools/art/export_aseprite.py
# 3. Сборка data-URI в static/sprites.js и static/terrain.js
python tools/art/build_art.py
# 4. Проверка, что PNG совпадают с .aseprite
python tools/art/export_aseprite.py --check
python tools/art/build_art.py --check
```

Aseprite ищется в `ASEPRITE`, `C:\tools\aseprite\aseprite.exe`,
`C:\Users\<user>\src\aseprite\build\bin\aseprite.exe` и стандартных местах.

## Биомы подземелья

Темы идут по кругу `TERRAIN_FLOORS`, файлы — `floors/01…10`:

| № | Тема | Характер |
|---|---|---|
| 1 | Пещеры новичка | холодный сине-серый камень, золотые акценты |
| 2 | Мшистые пещеры | тот же камень, но с зеленью |
| 3 | Забытые катакомбы | тёплый песчаник, кости в швах |
| 4 | Затонувшие склепы | синий камень, тёмные подтёки |
| 5 | Ледяные залы | светлый лёд, белые трещины |
| 6 | Стылые глубины | тёмный лёд, синие грани |
| 7 | Обитель демонов | тёмно-красная порода, угли в трещинах |
| 8 | Кузни преисподней | бурый камень, золото и угли |
| 9 | Обсидиановые чертоги | фиолетовое стекло, неоновые прожилки |
| 10 | Логово дракона | багровая порода, золотые вкрапления |

Правила:

- стены темнее пола; пол — не меньше +0.1 по яркости;
- у каждой темы 6 вариантов стен и 6 полов, как у этажа 1;
- пол делается на wrapping-Voronoi, стены — на кладке; швов при
  повторе 3×3 быть не должно;
- детали (мох, кости, лёд, угли, прожилки, золото) — редкие, 1–2 px,
  они не должны превращать пол в шум;
- темы 7 и 10 (`6` и `9` в старом коде) — огненные: вода на них
  превращается в лаву, кости — в колья.

## Вода, лава, ловушки, лестницы, двери

- **Вода** — тёмно-синяя, 4 кадра основы и 8 прозрачных накладок пены
  (`wave_E/N/S/W`). Основа должна стыковаться сама с собой; пена — только
  тонкие штрихи, иначе вода начинает спорить с героем.
- **Лава** — 6 полных кадров, тёмная корка и сеть светящихся трещин.
  Лава не тонируется сборкой: это опасность, она должна быть ярче пола.
- **Ловушки** — 6 штук. На карте они рисуются клеткой 0.46 и с
  `opacity: 0.3`, поэтому силуэт важнее деталей: 3 крупных шипа, большая
  дыра, крест из верёвок, одна крупная шляпка гриба, 3 кристалла, круг
  рун. Не добавляйте мелкую текстуру — она исчезнет.
- **Лестницы** — 2 кадра вниз и 2 вверх. Вниз: светлый верхний порог и
  тёмный проём; вверх: светлый проём и золотой блик. Кадры отличаются
  одной искрой, чтобы не мигало.
- **Двери** — обычная и запертая. Запертая получает цепь и золотой замок;
  это единственная яркая деталь, остальное — дерево и железо.

## Декор и деревня

- **Плоский декор** (трава, мох, кости, кристаллы) лежит на полу: без
  крупных теней, 1–2 цвета плюс акцент, чтобы не спорить с существом.
- **Декор-предметы** (колодец, колья, костёр, обломки) стоят в клетке
  отдельным слоем и приглушаются CSS. Колодец одновременно служит
  деревенским колодцем, поэтому у него есть крыша и фонарь.
- **Деревня**: стена — светлая штукатурка с тёмным фахверком, крыши —
  тёмная черепица (крыша обязана быть темнее фасада), окно — тёплая
  рамка с цветочным ящиком, земля — утоптанный грунт с травой и камнями.
- **NPC-база**: один спрайт с синим кафтаном; `build_art` перекрашивает
  кафтан в семь оттенков. Контур добавляет сборка, в исходнике его нет.
- **Дерево** — отдельная иконка `TERRAIN_ICONS.tree`, а не SVG-заглушка.
- **Интерьер дома** — отдельная тема `11`: деревянные стены и дощатый пол,
  без уличного фасада. Дома внутри больше не выглядят комнатами подземелья.

## Анимации

- **Покой** — `enemyIdle`: сдвиг ровно на 2 px вверх, без дробного `scale()`.
  У героя и NPC анимация висит на картинке, у врагов — на клетке.
  `--idle-dur` и `--idle-delay` считаются из координат в `place()`, поэтому
  толпа не дышит синхронно.
- **Бой** — `strikeRight`/`strikeLeft` (выпад), `fighterFlash` (вспышка при
  уроне), `fighterDown` (падение: наклон, тень, серость). Босс в сцене
  рисуется 128×128, обычный боец — 96×96.
- **Reduced motion** — системный `prefers-reduced-motion` и класс
  `body.reduce-motion` отключают всё это.

## Портал и фон меню

- **Портал** — каменная арка с фиолетово-голубым вихрем; свечение и пульс
  добавляет CSS `.ent-portal`, в спрайте их нет. Он же используется в фоне
  главного меню.
- **Фон меню** (`menu-bg.js`) собирается из настоящих `TERRAIN_FLOORS`,
  `TERRAIN_DECOR`, сундука, бочки, лестницы и портала. Пока PNG
  декодируются, остаётся процедурный fallback, поэтому меню не мигает.

## Проверка перед «готово»

- [ ] спрайт читается на 25×25 px на полу этажа 1;
- [ ] контур не рвётся и не толще 1 px;
- [ ] свет сверху-слева, тень снизу-справа;
- [ ] нет случайных цветов вне палитры;
- [ ] предмет не выходит за 32×32 и не обрезан;
- [ ] тайл не даёт шва при повторе 3×3;
- [ ] стена темнее пола;
- [ ] в бою портрет 96×96 не выглядит мутным;
- [ ] `export_aseprite.py --check` и `build_art.py --check` проходят.
