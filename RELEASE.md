# Публичный релиз PyDungeon

Публичная версия — одиночная браузерная игра. Сервер, аккаунты, общая база
результатов и панель преподавателя в неё не входят.

## 1. Перед сборкой

- [ ] Обновлена версия в `static/web-boot.js`, `package.json` и CHANGELOG.
- [ ] Проверены меню, новая игра, сохранение и загрузка.
- [ ] Обычный вход без `?gen` строит этажи генератором v3; `?gen=v2` в
      dev-сборке возвращает старые планировки.
- [ ] Кампания v2 пройдена на v3: 15 этажей, пять боссов, тайники и крипта.
- [ ] Проверены HUD и журнал кампании.
- [ ] Проверены деревня, бои, магазин, кузница и финал.
- [ ] На мобильном экране HUD не перекрывает управление.

## 2. Сборка

```bash
python tools/build_web.py
python tools/fetch_pyodide.py
```

Проверка:

```bash
python verify_web.py --browser msedge
python run_all_checks.py --quick
```

## 3. GitHub Pages

- [ ] Содержимое `standalone/build/` лежит в корне `gh-pages`.
- [ ] В корне есть `.nojekyll`.
- [ ] `index.html` открывает главное меню.
- [ ] Нет запросов к `/api/*`.

## 4. Itch.io

```bash
python tools/package_web.py
```

- [ ] Zip содержит `index.html` в корне.
- [ ] Игра запускается как HTML5.
- [ ] Pyodide загружается локально.
- [ ] Сохранения переживают перезагрузку страницы.

## 5. Definition of Done

- [ ] `verify_web.py` — все проверки зелёные.
- [ ] `run_all_checks.py --quick` — без падений.
- [ ] Публичная сборка не обращается к серверу.
- [ ] Игра проходится на десктопе и телефоне.
- [ ] Из интерфейса не осталось ссылок на старые учебные разделы.
