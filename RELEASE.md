# Чек-лист публичного релиза (Itch.io, web)

Версия 1.0.0 должна быть **отдельной web-сборкой**: без сервера, аккаунтов,
друзей, панели учителя и админки. Серверная версия остаётся для занятий.

## 1. Что входит в 1.0

- Подземелье: 10 этажей, 3 сложности, бесконечный режим.
- Локальный профиль и сохранения (localStorage).
- Проверка Python-кода через Pyodide в Web Worker.
- Главное меню: начать/продолжить поход, деревня, настройки, аккаунт.
- Калибровка из шести вопросов и выдача заданий по стартовому уровню.
- Онбординг первых 10 минут и итог похода.
- Экспорт/импорт сейва (если успеваем; иначе — после 1.0).

Не входит: аккаунты, друзья, учительская панель, серверный античит,
сгенерированные код-задания без серверных тестов, тест/тренажёр/study.

## 2. Сборка

```bash
python tools/build_web.py
python tools/fetch_pyodide.py
python tools/package_web.py
```

Ожидаемый результат:

- `standalone/build/index.html` — редирект в главное меню;
- `standalone/build/game.html` — игра;
- `standalone/build/static/pyodide/` — локальный Pyodide (~13 МБ);
- `dist/pydungeon-standalone-<версия>.zip` (~6 МБ), `index.html` в корне;
- в конце печатается sha256 архива.

Проверить локально:

```bash
python -m http.server 8080 --directory public
# открыть http://127.0.0.1:8080/
```

## 3. Smoke-тесты перед загрузкой

Автоматически (нужен Playwright, `python -m pip install playwright`):

```bash
python verify_web.py                 # Chromium от Playwright
python verify_web.py --browser msedge  # системный Edge, без скачивания
```

Проверяет старт, карту, Pyodide (3/3 и провал), локальный сейв и
«Продолжить», отсутствие запросов к `/api/*` и ошибок в консоли.

Минимум вручную в Chromium/Edge и Firefox:

- [ ] Корень сайта открывает главное меню; имя меняется в строке аккаунта,
      «Настройки» — шестерёнка.
- [ ] Классическое главное меню: крупное название и один вертикальный список
      действий; ↑↓/Enter/Esc; настройки — шестерёнка в правом верхнем углу;
      аккаунт — строка игрока внизу.
- [ ] Вход/регистрация по строке аккаунта; в веб-сборке — имя вместо PIN.
- [ ] «Начать поход» открывает окно стража и ставит в него фокус; «Продолжить
      поход» поднимает сейв; «В деревню» сохраняет поход; «Выход» сохраняет и
      уводит на главную; на титульном экране видна карта, а шапка, HUD и
      журнал скрыты.
- [ ] В веб-сборке «Изменить имя» сохраняет профиль, поход и «Продолжить
      поход»; занятое имя не затирается.
- [ ] Настройки по шестерёнке: звук, громкость, полный экран, «меньше
      анимации» и памятка по управлению; переживают перезагрузку.
- [ ] Под меню герой не ходит, E и пробел не срабатывают; «Меню» в шапке
      открывает его во время игры.
- [ ] Перед первым спуском открывается калибровка: 6 вопросов, уровень
      сохраняется после перезагрузки и при входе на другом компьютере.
- [ ] В `/results` у нового результата заполнена колонка «Старт».
- [ ] Если есть сейв — видна «Продолжить поход», она поднимает сохранение.
- [ ] В деревне виден «Следующий шаг», у стража открывается окно спуска.
- [ ] Новая игра: этаж 1, HP, золото 0, сейв создан.
- [ ] Перезагрузка страницы: сохранение на месте.
- [ ] Задание на код: верная функция проходит 3/3, неверная — меньше.
- [ ] Офлайн: заблокировать `cdn.jsdelivr.net` в DevTools — проверка кода
      продолжает работать (Pyodide локальный).
- [ ] `localStorage.clear()` + перезагрузка: игра не падает, создаётся
      новый профиль.
- [ ] Битая запись сейва (`pyquiz_save_v1:*`) не роняет `game.html`.
- [ ] Мобильный viewport 390×844: стартовый экран читается, карта
      прокручивается/масштабируется, кнопки действия доступны.
- [ ] Кнопка `⛶` входит в полноэкранный режим и выходит из него; карта
      растягивается на весь viewport (`#map-scroll` = `innerWidth × innerHeight`).
- [ ] Шапка, HUD, журнал, миникарта и кнопки действия остаются поверх карты;
      кнопка HUD скрывает и возвращает панель героя.
- [ ] В консоли нет запросов к `/api/*`.
- [ ] В консоли нет ошибок, кроме ожидаемых 404 при проверке отсутствия
      необязательных файлов.

### Статус проверки (2026-10-22, Chromium и Edge на Windows)

Автотест на Windows: `python verify_web.py --browser msedge` — **16/16**:

- корень сайта открывает главное меню, видит игрока;
- в главном меню есть «Начать поход»;
- «Начать поход» закрывает меню, открывает окно стража и ставит в него фокус;
- карта рисуется (416 плиток в деревне), сборка в веб-режиме без сервера;
- Pyodide: верное решение — 3/3, неверное — 1/3;
- поход создаёт локальный сейв, меню поднимает его;
- запросов к `/api/*` нет, консоль без ошибок.

Проверено руками в реальном браузере (Playwright, локальная сборка `standalone/build`):

- корень сайта: `game.html?menu=1`, главное меню, имя в аккаунте;
- карта рисуется: 416 плиток в деревне, 660 в подземелье;
- Pyodide: верный `attack_power` — 3/3, неверный — 1/3; первый запуск ~4 с;
- поход создаёт локальный сейв, меню поднимает его;
- **внешних запросов нет вообще** (Pyodide полностью локальный, проверено по
  `performance.getEntriesByType("resource")`), запросов к `/api/*` нет;
- `localStorage.clear()` — корень снова открывает меню;
- битый JSON и `player: null` в сейве не роняют игру;
- мобильный 390×844: нет горизонтальной прокрутки, карта скроллится, шапка
  и кнопка панели героя видны;
- **калибровка**: 6 вопросов, сохранение уровня, повторный запуск, пропуск,
  мобильный 390×844; в серверной версии уровень доезжает до профиля и до
  колонки «Старт» в `/results`;
- **классическое меню**: один список действий, шестерёнка настроек (включая
  памятку по управлению), строка аккаунта, ↑↓/Enter/Esc; «Начать поход»
  открывает стража и ставит туда фокус, «В деревню» сохраняет поход;
  переименование в веб-сборке переносит профиль и сейв; вход и регистрация в
  серверной версии, имя вместо PIN в веб-сборке; настройки звука и громкости,
  полный экран, «меньше анимации» переживают перезагрузку; 1024×720 и 390×844;
- консоль без ошибок.

Осталось проверить: Firefox, кнопку `⛶`, окно стража и «следующий шаг»,
touch-управление, Itch-iframe, меню и настройки на Firefox и мобильном,
калибровку на живом уроке.

## 4. Браузеры и ограничения

- Chromium/Edge — основной.
- Firefox — обязателен перед public.
- Safari/iOS — по возможности; Pyodide и localStorage требуют проверки.
- Itch.io iframe: относительные пути, без абсолютных `/static/`.
- Pyodide ~13 МБ: первый запуск проверки кода дольше; нужен индикатор
  «Загружаем Python…» (сейчас кнопка «Проверяем...»).
- Web-сборка однопользовательская: результаты и античит локальные.

## 5. Itch.io

- Тип проекта: HTML.
- Загрузить zip из `dist/` (index.html в корне).
- Embed: включить fullscreen и мобильную версию.
- Обложка: 630×500 или больше; скриншоты 16:9; GIF первого боя.
- Теги: `python`, `roguelike`, `educational`, `pixel-art`, `procedural`,
  `singleplayer`, `keyboard`, `touch`.
- В описании: «Python-рогалик: отвечай, пиши код, поднимай деревню».
- Отдельно указать: локальные сохранения, без аккаунтов, играется в браузере.

## 6. Definition of Done для 1.0

- [ ] Все smoke-тесты выше пройдены.
- [ ] 10–20 тестеров прошли первый поход; собраны ответы:
      где остановились, что непонятно, что слишком длинно.
- [ ] 0 P0/P1 багов в трекере.
- [ ] Баланс: 70% — 65–75% побед, 60% — 45–55%, 50% — 5–15%.
- [ ] Сейв переживает перезагрузку, импорт/экспорт (если есть).
- [ ] Офлайн-режим с локальным Pyodide.
- [ ] Версия и changelog обновлены.
- [ ] `standalone/build/` и `dist/` не в git; архив воспроизводится командами выше.
