# PyDungeon

Тёмное фэнтези-подземелье, где бой — это проверка знаний Python.
Пятнадцать этажей, деревня-хаб, кампания, боссы и сохранения в браузере.

**Играть:** https://jellyfish2077.github.io/Dungeon-of-Python/

## Что внутри

- Кампания «Печати глубины»: шесть глав, журнал, пролог и финал.
- Первая глава — знакомство с жителями; у каждого жителя приветствие и диалоговая сцена.
- Деревня: амбар, колодец, кузница, дом мастера, торговец, школа и жители.
- Школа: курс Python из 9 модулей по три урока и доска практических задач.
- Пошаговые бои: вопрос по Python, затем задача на ту же тему.
- Пять боссов с титулами, тремя фазами арены и постоянными трофеями.
- Боссы патрулируют арену и сами начинают бой, когда герой входит в зал.
- Пятнадцать этажей и пять биомов: пещеры, катакомбы, лёд, демоны, логово дракона.
- Полный поход занимает примерно 30–55 минут.
- Три исхода похода: победа, смерть с выбором золота или разбора, отступление с 75% золота.
- Знамения похода и алтарь сделки: риск, награда или пройти мимо.
- Снаряжение, щиты, редкости, комплекты, зелья, амулеты возврата.
- Постоянный HUD: здоровье, опыт, золото, сила, защита и текущая глава.
- Журнал кампании: сюжет, поручения и архив.
- Пиксель-арт 32×32: Aseprite и открытые тайлы DCSS (CC0).
- Работает без сервера: профиль и сохранения лежат в `localStorage`,
  а резервную копию можно выгрузить и загрузить из окна сохранений.

## Управление

| Клавиша | Действие |
|---|---|
| `WASD` / стрелки | ходьба по карте; удерживайте ~2 секунды — герой пойдёт сам |
| `E` | действие: дверь, сундук, лестница, житель |
| `Пробел` | пропустить ход |
| `I` | инвентарь |
| `M` | мини-карта |
| `Esc` | пауза или закрыть окно |
| колесо мыши | зум карты |

## Локальный запуск

Нужен Python 3.10+.

```bash
python tools/build_web.py
python tools/fetch_pyodide.py
python launch_standalone.py
```

`launch_standalone.py` поднимет локальный сервер и откроет игру в браузере.
Без Pyodide игра запустится, но проверка кода будет тянуть runtime с CDN.

Для локальной отладки соберите версию с панелью разработчика:

```bash
python tools/build_web.py --dev
```

Кнопка DEV появляется только в такой сборке; публичная версия без `--dev`
её не показывает. Панель открывается клавишей `P`: этажи, игрок, бой,
квесты, деревня, предметы, множители баланса и отладка. Подробнее —
`docs/DEV_TOOLS.md`.

Быстрый обзор контента без запуска браузера:

```bash
node tools/dev_toolkit.js floors
node tools/dev_toolkit.js bosses
node tools/dev_toolkit.js balance
node tools/dev_toolkit.js floor 3
```

Можно запустить и вручную:

```bash
python -m http.server 8080 --directory standalone/build
```

## Проверки

```bash
python run_all_checks.py            # всё: контент, node, браузер, аудит сборки
python run_all_checks.py --quick    # контент и генераторы, нужен Node.js
python verify_content.py            # ссылки, id, боссы, курс
python verify_web.py --browser msedge
python verify_scenarios.py --browser msedge
python build_audit.py               # DEV-флаги, секреты и битые ссылки
```

`verify_web.py` собирает standalone-версию и проверяет игру в браузере:
меню, сохранения, Pyodide, HUD, журнал, отсутствие запросов к API.

`verify_scenarios.py` собирает DEV-версию и прогоняет сценарии: все пять
боссов с фазами и трофеями, приветствие учителя и удержание клавиши.

`build_audit.py` пересобирает публичную версию и проверяет, что в неё не
попали DEV-флаги, секреты, админ-файлы и битые ссылки на ассеты.

```text
  menu.js menu.css              главное меню и пауза

  village-content.js            деревня и дома
  questions.js                  банк вопросов
  variants.js practice-variants.js
  code-tasks.js code-tasks-tests.json
  items.js icons.js
  sprites.js terrain.js         пиксель-арт
  profile.js auth.js web-boot.js
tools/
  build_web.py                  сборка standalone/build
  fetch_pyodide.py              офлайн-Pyodide
  package_web.py                zip для Itch.io
  art/                          Aseprite-исходники и сборка графики
standalone/
  build/                        публичная сборка
```
